### 👨‍💻 About Me

Saya adalah seorang **Pendidik** dan **Full-Stack Developer** yang berfokus pada pengembangan sistem informasi sekolah, alat bantu administrasi guru, dan integrasi kecerdasan buatan (AI) lokal untuk efisiensi ekosistem pendidikan.

- 🔭 **Sedang Mengembangkan:** **MUHONE PWA Ecosystem** (sistem terpadu manajemen sekolah) & **Asisten Mengajar**.
- 💡 **Minat Utama:** Web Architecture, Progressive Web Apps (PWA), Local AI/LLM Integration (Ollama, Qwen), dan Server Automation.
- ⚡ **Aktivitas:** Mengajar, merancang infrastruktur VPS, dan sesekali bermain futsal bersama tim guru!
